Book Tribe - Frontend (English)

Overview:
This folder contains the Angular frontend for the Book Social Network. It provides the user interface, communicates with the backend API, and supports development tooling via the Angular CLI.

How to run (development):
- Install dependencies: npm install
- Serve locally: ng serve (or npm start if configured)

Key files and folders:
- angular.json - Angular CLI configuration
- package.json / package-lock.json - Node dependencies and scripts
- src/ - Angular application source (components, services, assets)
- tsconfig*.json - TypeScript configuration files

Notes:
- Use Node and the Angular CLI matching the project's configuration. See top-level README for full setup and Keycloak integration.
